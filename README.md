# 619 - Discipline Daily 👋

This is an [Expo](https://docs.expo.dev/versions/v57.0.0/) project built with [Expo Router](https://docs.expo.dev/versions/v57.0.0/router/introduction/).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in:

- A [development build](https://docs.expo.dev/versions/v57.0.0/develop/development-builds/introduction/)
- An [Android emulator](https://docs.expo.dev/versions/v57.0.0/workflow/android-studio-emulator/)
- An [iOS simulator](https://docs.expo.dev/versions/v57.0.0/workflow/ios-simulator/)
- [Expo Go](https://docs.expo.dev/versions/v57.0.0/workflow/expo-go/), a limited sandbox for trying out app development with Expo

You can start developing by editing the files inside the **src/app** directory. This project uses [file-based routing](https://docs.expo.dev/versions/v57.0.0/router/introduction).
